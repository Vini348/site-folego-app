# Site do Fôlego

Landing page estática, responsiva e sem dependência de build. Abra `index.html` para visualizar localmente ou publique a pasta inteira em Netlify, Vercel ou GitHub Pages.

- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual, animações e responsividade.
- `script.js`: menu mobile e animações de entrada.
- `assets/favicon.svg`: ícone da marca.

As telas de produto exibidas na landing page são prévias ilustrativas desenhadas para apresentar os principais fluxos sem revelar toda a interface interna. Ajuste os dados de demonstração antes de uma campanha pública, caso queira usar métricas reais de uma conta específica.
